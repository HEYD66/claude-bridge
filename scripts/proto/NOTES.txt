== 启动参数 ==
claude -p --input-format stream-json --output-format stream-json --verbose --include-partial-messages
  --replay-user-messages --permission-prompt-tool stdio [--prompt-suggestions] [--resume SID]
  [--resume-session-at UUID --fork-session] + env CLAUDE_CODE_ENABLE_SDK_FILE_CHECKPOINTING=1

== 输入（stdin，每行 JSON）==
user: {type:'user',message:{role:'user',content:[{type:'text',text},{type:'image',source:{type:'base64',media_type,data}}]},parent_tool_use_id:null,session_id:'',uuid?,priority?:'now'|'next'|'later'}
  - 运行中发送默认排队；priority:'now' 会打断当前轮（result stop_reason null）后立即执行
  - 出队执行时回显 {type:'user',...,uuid(我们给的),isReplay:true}
  - 排队时有 {type:'command_lifecycle',command_uuid,state:'queued'|'completed'}
control_request: {type:'control_request',request_id,request:{subtype,...}} → control_response {type:'control_response',response:{subtype:'success'|'error',request_id,response|error}}
  initialize → {commands[{name,description,argumentHint}],agents,output_style,available_output_styles,models[{value,resolvedModel,displayName,description,supportsEffort,supportedEffortLevels,supportsFastMode}],account,claude_code_version,current_permission_mode,fast_mode_state...}
  interrupt → {still_queued:[]}；result subtype=error_during_execution
  set_model {model}；set_permission_mode {mode} → {mode}
  get_context_usage {detail:'summary'} → {categories[{name,tokens,kind}],totalTokens,maxTokens,percentage}
  get_usage {skip_behaviors:true} → {session:{total_cost_usd,...,model_usage},rate_limits_available,rate_limits}
  get_session_cost → {text}
  rewind_files {user_message_id,dry_run?} → {canRewind,filesChanged,insertions,deletions} / {canRewind,skippedLinks}
  cancel_async_message {message_uuid}；list_permission_rules → {state:{rules[{behavior,source,rule,editability}]}}
  file_suggestions {query}；get_plan；get_settings；update_settings；stop_task {task_id}
CLI→host: control_request can_use_tool {tool_name,display_name,input,description,permission_suggestions[],blocked_path,decision_reason,tool_use_id,requires_user_interaction}
  回复 {behavior:'allow',updatedInput,updatedPermissions?:suggestions} | {behavior:'deny',message}
  AskUserQuestion: updatedInput={...input,answers:{[question]:'label'（多选逗号分隔）},annotations?}
  ExitPlanMode（plan 模式下）: requires_user_interaction，input 可能为 {}；allow=批准
  control_cancel_request（CLI 取消待处理请求）

  Write: {type:'create'|'update',filePath,content,structuredPatch,originalFile}；Edit: structuredPatch[{oldStart,oldLines,newStart,newLines,lines}]）
stream_event、result、prompt_suggestion{suggestion}、rate_limit_event{rate_limit_info}、command_lifecycle
parent_tool_use_id≠null → 子代理消息
